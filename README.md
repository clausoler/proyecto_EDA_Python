# Bank Marketing Campaign Analysis

## Descripción del proyecto

Este proyecto desarrolla un análisis exploratorio de datos (EDA) sobre campañas de marketing bancario con el objetivo de identificar los principales factores relacionados con la suscripción de un producto financiero.

A lo largo del proyecto se realiza:
- exploración inicial de datos,
- limpieza y transformación,
- feature engineering,
- análisis exploratorio,
- análisis temporal,
- análisis geográfico,
- análisis de correlaciones,
- detección de outliers,
- y extracción de insights de negocio orientados a la optimización de campañas comerciales.

---

# Objetivo del proyecto

El objetivo principal es analizar el comportamiento de los clientes durante campañas de marketing bancario para detectar patrones y variables relacionadas con la conversión de clientes.

# Principales insights del proyecto

- Las llamadas más largas aumentan la conversión.
- El exceso de contactos reduce la efectividad.
- Los clientes con campañas previas exitosas convierten más.
- Los clientes recientes presentan mayores tasas de suscripción.
- El canal móvil resulta más efectivo.
